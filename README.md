# 🧩 Part A: Customer Segmentation Using K-Means

## 💼 Business Problem

An online retailer wants to understand different types of customers.

The available information includes:

| Feature          | Description                                         |
| ---------------- | --------------------------------------------------- |
| Monthly Spending | Amount spent by the customer each month             |
| App Visits       | Number of times the customer visits the application |

K-Means Clustering is used to divide the customers into **3 groups**.

---

## 📊 Dataset

The practical uses a small customer dataset containing eight customers:

| Customer | Monthly Spending | App Visits |
| -------- | ---------------: | ---------: |
| A        |             9000 |         20 |
| B        |             8500 |         18 |
| C        |             1200 |          3 |
| D        |             1500 |          4 |
| E        |             5000 |         10 |
| F        |             5500 |         12 |
| G        |             8800 |         19 |
| H        |             1800 |          5 |

The customer name is used only as an identifier. The clustering model uses:

* **Monthly Spending**
* **App Visits**

---

## 🤖 K-Means Clustering

The project applies K-Means with:

```python
KMeans(n_clusters=3, random_state=42, n_init=10)
```

The model assigns every customer to one of three clusters.

### Important

The cluster numbers **do not represent good, average, or bad customers**.

For example:

* Cluster 0
* Cluster 1
* Cluster 2

are simply labels generated by the model.

The actual meaning of each cluster should be determined by examining:

* Spending behaviour
* App activity
* Customer behaviour
